StockPreview v5 - Portable Release
==================================

Cach chay tren may khac:
1. Copy NGUYEN folder release_v5 sang may Windows khac.
2. Mo folder release_v5.
3. Double-click RUN_STOCK_PREVIEW_v5.bat.

Khong can cai Python tren may khac neu build thanh cong.

Lan dau chay:
- Them Pexels API key trong app.
- Chon output folder de luu stock media.
- Neu dung MotionArray Helper, nen cai Coc Coc hoac Chrome tren may do.

Du lieu app luu tai:
- Config: %USERPROFILE%\.stock_preview_v4_config.json
- State:  %USERPROFILE%\.stock_preview_v4_state.pkl
- Cache:  %USERPROFILE%\.stock_preview_cache_v4\

Neu app khong mo duoc:
- Thu chay StockPreview_v5\StockPreview_v5.exe truc tiep.
- Dam bao Windows 10/11 64-bit.
- Neu bi antivirus chan, allow app/folder release_v5.

Build lai:
- Chay BUILD_RELEASE_v5.bat trong folder source.
